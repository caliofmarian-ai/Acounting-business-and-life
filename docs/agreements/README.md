## Legal publication rule

Documents marked LEGAL_REVIEW_RECOMMENDED remain drafts until:
- operator/entity facts are verified;
- commercial/worker/party relationships are defined;
- applicable Philippines law/regulation is reviewed;
- Project Owner approves the final controlled version.

No draft agreement may silently create employment, agency, partnership or government authorization.
