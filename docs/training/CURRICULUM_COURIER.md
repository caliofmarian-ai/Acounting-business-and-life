# Curriculum — Delivery Provider / Courier

## Audience

Approved Courier/Delivery Provider profiles.

## Learning objectives

- Operate only while eligible.
- Follow allowed delivery states.
- Use location only for active delivery.
- Protect Customer data/handoff code.
- Recognize safety/compliance escalation.

## Prerequisite knowledge / access

- None beyond applicable onboarding prerequisites.

## Modules

### Module 1 — Eligibility
- documents/status/expiry
- approval before availability
- platform vs government authority

### Module 2 — Assignment
- available/assigned
- Merchant ready+paid gate
- vehicle scope

### Module 3 — Active route
- status sequence
- pickup
- location purpose

### Module 4 — Handoff
- arrive at Customer
- completion code
- no premature code request

### Module 5 — Safety/privacy
- Customer address/contact
- incident response
- no unauthorized cash custody

### Module 6 — Compliance
- LTO/vehicle evidence where applicable
- LTFRB applicability not assumed
- external qualifications separate

## Practical exercises

1. Run a simulated delivery from assignment to handoff.
2. Identify when location sharing must stop.
3. Handle wrong completion code without bypassing control.

## Competency / knowledge check

- Explains approval-before-availability.
- Follows state transitions.
- Protects handoff code/location.
- Escalates safety issue.

## Critical errors / retraining triggers

- Operating while unapproved/expired.
- False delivery completion.
- Premature handoff-code request.
- Off-duty/irrelevant location collection.
- Sharing Customer data.

## Required controlled documents

- PLAYBOOK_COURIER.md
- SOP_DELIVERY.md
- COURIER_AGREEMENT.md
- DELIVERY_LOCAL_SERVICES_RESEARCH.md

## Training evidence generated

- Training acknowledgement.
- Delivery simulation/assessment.
- Safety/privacy check.

## Access dependency

Training is required by policy but runtime access dependency is not enforced until the corresponding authorization/RBAC workflow implements it.

## Refresher

Refresher cadence is **TO BE APPROVED**. A refresher is also required after material MAJOR changes to the role's SOP, legal/compliance requirements, money-handling controls or privileged access.

## Certification boundary

A Business & Life training-completion record is an internal/platform record. It must not be represented as a PRC licence, TESDA National Certificate, government certificate or other external professional qualification unless that external credential was separately issued and verified.
