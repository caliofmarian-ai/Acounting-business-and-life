8. `08 — Local Services catalog`

Each profile catalog uses the same public documentation pattern:

```text
Profile purpose
  → Start here
  → End-to-end journey
  → Guide catalog
  → Common questions / troubleshooting
```

The website equivalents are rendered from `public/help/content.json` and the profile-specific SVG flows under `public/help/flows/`.

Visual rule: diagrams exist to explain a workflow or boundary. Decorative visuals must not replace operational information.
