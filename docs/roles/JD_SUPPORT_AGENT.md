# Job Description — Support Agent

## Role purpose

Resolve user and operational support issues using documented procedures without exceeding access authority.

## Reporting / authority relationship

Reports to Territory/Country Support lead or delegated Admin.

## Core responsibilities

- Receive/classify requests.
- Verify identity using approved process.
- Provide documented self-service guidance.
- Gather only necessary information.
- Escalate money/security/compliance/safety cases.
- Record actions and outcomes.

## Permitted actions

- View data necessary for assigned support case.
- Guide account/profile/order workflows.
- Request approved supporting information.

## Prohibited actions

- Ask for passwords/secrets.
- Access unrelated private evidence.
- Promise refunds/approvals outside authority.
- Delete/alter financial history to 'fix' an issue.

## Daily / active-case duties

- Work assigned queue.
- Maintain case notes.
- Use relevant Help/SOP links.
- Escalate blockers promptly.

## Periodic duties

- Review recurring issue trends.
- Complete refresher training.
- Report documentation gaps.

## Privacy / confidentiality

- Data minimization.
- No private data in public comments.
- Use controlled case/evidence storage.

## Money / financial handling

- No false payment claims.
- Money disputes require finance/payment evidence and escalation.

## Legal / compliance boundary

- Do not provide personalized legal/tax advice beyond approved guidance.
- Use current country/territory docs.

## Required training

- Support tools.
- Privacy.
- Account recovery.
- Order/delivery/service workflows.
- Escalation and de-escalation.

## Required evidence / records

- Support case notes.
- Identity verification evidence allowed by policy.
- Escalation record.

## Escalation

- Security/privacy → Trust & Safety/Security.
- Money → Finance/reconciliation.
- Profile approval → Admin/Compliance.
- Legal → Country Compliance.

## KPI framework

- Resolution quality.
- First-response time.
- Reopen/escalation accuracy.
- Privacy/security errors.
- User self-service success.

## Required acknowledgements

- Support code of conduct.
- Privacy/confidentiality.
- No-password policy.
- Escalation SOP.
