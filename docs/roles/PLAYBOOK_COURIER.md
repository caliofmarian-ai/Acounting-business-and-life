# Profile Playbook — Delivery Provider / Courier

## Purpose

Perform only approved delivery assignments safely and transparently within eligibility, vehicle and territory rules.

> This is an operational profile playbook. It does **not** determine or imply employment, contractor, agency, franchise, partnership or worker status.

## Responsibilities

- Maintain valid eligibility/evidence.
- Set Availability truthfully.
- Follow assigned pickup/drop-off.
- Share location only for active delivery purpose.
- Protect Customer handoff code/privacy.
- Report incidents.

## Permitted actions

- Submit eligibility documents.
- Go available when approved.
- Work assigned deliveries.
- Share active location.
- Complete with correct handoff code.

## Prohibited actions

- Operate while suspended/expired/unapproved.
- Share Customer data/location outside delivery purpose.
- Request handoff code before actual handoff.
- Falsify delivery completion.
- Accept unauthorized cash custody where policy does not allow it.

## Normal operating workflow

1. Check eligibility/vehicle readiness.
2. Set availability.
3. Accept/follow assignment.
4. Verify pickup/order.
5. Navigate active route.
6. Complete secure handoff.

## Privacy / confidentiality

- Use location only for active job.
- Protect Customer address/contact.
- Do not retain/share route data unnecessarily.

## Money / commercial handling

- Do not collect/hold money outside approved payment/cash-custody policy.
- Do not alter delivery/merchandise financial records.

## Legal / compliance boundary

- Vehicle/licence/insurance/transport requirements depend on current official PH/territory rules and service model; follow SOURCE_VERIFIED checklist.
- Platform eligibility is not government licence.

## Training / competency

- Delivery app/workflow.
- Safety.
- Privacy/location.
- Incident handling.
- Vehicle/document requirements.

## Evidence / documents

- Profile/identity evidence.
- Vehicle/document evidence as applicable.
- Expiry dates.
- Training acknowledgements.

## Escalation

- Safety incident → emergency/local procedure + platform incident.
- Eligibility → Admin/Reviewer.
- Payment/cash dispute → Support/Finance.
- App issue → Support.

## KPI / quality indicators

- Delivery completion.
- Failed/cancelled rate.
- Handoff verification.
- Safety incidents.
- Availability reliability.
- Document expiry compliance.

- Location use.
- Eligibility obligations.
- No-false-completion rule.
