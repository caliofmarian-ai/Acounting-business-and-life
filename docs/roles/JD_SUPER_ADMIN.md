# Job Description — Super Admin

## Role purpose

Operate and govern the platform globally within delegated authority.

## Reporting / authority relationship

Reports to Project Owner / Executive. Platform-wide authority is limited by protected Owner policy and audited permissions.

## Core responsibilities

- Manage delegated Country/Territory Admin authority.
- Oversee participant approval/suspension escalation.
- Review global operational health and audit evidence.
- Coordinate serious support/incidents.
- Protect RBAC boundaries.
- Enforce controlled policy versions.
- Escalate protected owner/legal/commercial decisions.

## Permitted actions

- Use platform-wide admin functions explicitly granted by RBAC.
- Approve/suspend within delegated scope.
- Review audit logs and case evidence for legitimate operational purposes.

## Prohibited actions

- Change protected commercial policy outside delegated bounds.
- Access private evidence without purpose.
- Present platform verification as government approval.
- Override audit/security controls without authorized emergency process.

## Daily / active-case duties

- Review critical queues and alerts.
- Handle escalated approval/suspension cases.
- Review security/operational anomalies.

## Periodic duties

- Review country/admin access.
- Audit delegated decisions.
- Review stale policies/credentials and system risk.

## Privacy / confidentiality

- Apply least privilege.
- Do not export/copy raw private evidence unnecessarily.
- Use audited admin paths.

## Money / financial handling

- Do not mark money paid/settled without authoritative evidence.
- Escalate unexplained reconciliation differences.

## Legal / compliance boundary

- Use current controlled legal/compliance guidance.
- Escalate uncertain interpretations instead of improvising.

## Required training

- RBAC/admin tools.
- Privacy/evidence handling.
- Incident escalation.
- Audit/log review.
- Global policy boundaries.

## Required evidence / records

- Admin actions/audit logs.
- Approval reasons.
- Suspension/reactivation evidence.
- Delegation records.

## Escalation

- Regulatory/legal ambiguity → Country Admin/Executive/compliance.
- Security incident → security response.
- Material finance anomaly → finance/Executive.

## KPI framework

- Admin decision quality/reversal rate.
- Queue age.
- Audit exceptions.
- Unauthorized-access incidents.
- Escalation timeliness.

## Required acknowledgements

- Admin code of conduct.
- Privileged-access policy.
- Confidentiality.
- Incident handling.
- Controlled-document acknowledgement.
