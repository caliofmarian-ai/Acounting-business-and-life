# Branded invitation layout example

`branded-invitation-demo.jpg` shows the runtime-owned
`BRANDED_INVITATION_V1` format using the approved Connected profiles artwork.
The image is complete at the top; the personal QR, scan instruction, name,
fallback code and full invitation link are in the white footer below.

This is a design example, not a real user's invitation. Its visible referrer is
`DEMO — not a real invitation`, its referral code is synthetic and its QR points
to the reserved `example.test` domain. Do not distribute it as a working
Business & Life invitation. Users create their real personal version through
the authenticated Marketing Kit after the release is deployed.

Generated with the actual `public/referral/marketing-kit-runtime.js` and
`growth/referral-qr.js`; no QR or personal information was added to the
approved source artwork itself.
